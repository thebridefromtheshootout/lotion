# Database Filter Bar UX Audit

Scope: the **filter bar** in the database webview — column select, operator select, value cell, and the "Create Filter Tile" button. The filter **tree** (the AND/OR/NOT group editor below) is out of scope; that part works well.

Source files: [`FilterBar.tsx`](src/webview/components/FilterBar.tsx), [`FilterValueInput.tsx`](src/webview/components/FilterValueInput.tsx), [`ColumnNameOptions.tsx`](src/webview/components/ColumnNameOptions.tsx), [`filterSort.ts`](src/webview/utils/filterSort.ts), [`databaseTypes.ts`](src/contracts/databaseTypes.ts).

---

## What works

- **Type-aware value cell for some types.** `FilterValueInput.inputKindFor` switches to a date picker for date columns, a number input for number columns, a checkbox for booleans, a `<select>` for single-select, and a multi-checkbox list for multi-select. The mechanism is good — it just doesn't reach every type/operator combination ([#1, #6](#findings)).
- **Staging area before commit to tree.** Tiles are built in the bar, dragged into the tree below — separates "construct a clause" from "place it in the boolean expression." Nice UX split.
- **Enter to submit.** The text-shaped value inputs submit on Enter. Good keyboard ergonomic.
- **Validation gate before staging.** [`isValidLeafValue`](src/webview/components/FilterBar.tsx#L266) refuses empty values except for `isempty`/`isnotempty`.

## Suggested order of attack

1. **Fix #1** (gate operators by column type) — single biggest UX win and unblocks #2, #10, #11 as side effects.
2. **Fix #2** (two-value `between` input) and #3 (chip builder for `in`/`!in`) — these turn currently-broken ops into usable ones.
3. **Fix #4** (regex validation in the bar) — quick win, removes a silent-failure class.
4. **Fix #6** (collapse `!`-operators into a leaf NOT toggle) — halves the operator alphabet, matches the existing tree NOT pattern.
5. **Fix #7** (search on multi-select picker) — purely additive, big payoff on real-world schemas.
6. Polish: #5 (label register), #8 (inline error), #11 (`isempty` cell), #12 (boolean tri-state).
